이룸 마케팅 홈페이지 배포 가이드

5단계로 끝내는 무료 호스팅 — 약 30분 소요

목차

  1. 사전 준비 (계정 만들기)
  2. 코드를 GitHub에 올리기
  3. Vercel에 연결해서 배포
  4. Formspree 폼 연동
  5. Google Analytics 연결
  6. 자체 도메인 연결
  7. 최종 체크리스트

1사전 준비

먼저 무료 계정 3개를 만듭니다. 각 5분이면 끝납니다.

서비스역할비용
GitHub코드 저장소무료
Vercel호스팅 (사이트 띄우기)무료
Formspree문의폼 → 이메일 자동 발송월 50건 무료
Google Analytics방문자 통계무료
💡 GitHub은 Vercel 가입할 때 "GitHub로 로그인"을 사용하면 한 번에 연결됩니다.

2코드를 GitHub에 올리기

방법 A — 가장 쉬움 (드래그 업로드)

  1. github.com/new 접속
  2. Repository name: erum-marketing 입력
  3. Public 선택 → Create repository 클릭
  4. 다음 화면에서 "uploading an existing file" 링크 클릭
  5. site/ 폴더 안의 모든 파일을 드래그해서 업로드 (assets 폴더 포함)
  6. 아래 Commit changes 클릭
⚠ site/ 폴더 자체를 올리지 말고, 그 안의 내용물(index.html, styles.css 등)을 올려야 합니다. 그래야 Vercel이 root에서 index.html을 찾습니다.

방법 B — 명령줄을 쓸 줄 안다면

cd site
git init
git add .
git commit -m "initial"
git branch -M main
git remote add origin https://github.com/YOUR_ID/erum-marketing.git
git push -u origin main

3Vercel에 연결해서 배포

  1. vercel.com → "Sign Up" → Continue with GitHub
  2. GitHub 권한 승인
  3. 대시보드에서 Add New… → Project 클릭
  4. 방금 만든 erum-marketing 저장소 옆 Import 클릭
  5. 설정 화면에서 그대로 Deploy 버튼 클릭 (별도 설정 불필요)
  6. 1~2분 기다리면 🎉 — 자동으로 erum-marketing.vercel.app 같은 주소가 나옵니다
💡 이후 GitHub에 파일을 수정/업로드하면 Vercel이 자동으로 다시 배포합니다 (수정 1분 내 반영).

4Formspree 문의폼 연동

지금 폼은 YOUR_FORMSPREE_ID라는 placeholder가 있습니다. 이걸 본인 ID로 바꿔야 실제 메일이 옵니다.

  1. formspree.io 가입
  2. 대시보드 → + New Form 클릭
  3. Form name: "이룸마케팅 상담", Send to: 받을 이메일 주소 입력
  4. 생성되면 endpoint가 나옵니다: https://formspree.io/f/abcdwxyz
  5. GitHub에서 index.html 편집 → YOUR_FORMSPREE_ID를 위 endpoint의 abcdwxyz 부분으로 교체
  6. Commit하면 1분 후 라이브 사이트에 반영됩니다
찾을 코드:
action="https://formspree.io/f/YOUR_FORMSPREE_ID"

바꿀 코드:
action="https://formspree.io/f/abcdwxyz" ← 본인 ID

5Google Analytics 연결

  1. analytics.google.com 가입
  2. 속성 만들기 → 웹 → 본인 도메인 입력
  3. 측정 ID를 받습니다 (형식: G-XXXXXXXXXX)
  4. index.html 상단의 주석 처리된 GA 블록을 찾아서:
    • <!-- 와 --> 두 개를 삭제 (주석 해제)
    • G-XXXXXXXXXX를 본인 측정 ID로 교체 (2곳)
  5. blog.html에도 같은 방식으로 추가하면 칼럼 페이지 통계도 잡힙니다

6자체 도메인 연결 (선택)

erum-marketing.vercel.app 그대로 써도 되지만, erum-marketing.kr 같은 자체 도메인이 더 좋습니다.

도메인 구입

  • 가비아 또는 호스팅케이알 — 한국어, .kr/.co.kr 추천
  • Namecheap — 영문, .com 저렴
  • 연 1.5만~3만원 정도

Vercel에 연결

  1. Vercel 프로젝트 → Settings → Domains
  2. 도메인 입력 (예: erum-marketing.kr) → Add
  3. Vercel이 알려주는 DNS 레코드(A / CNAME)를 도메인 구매한 곳의 DNS 설정에 입력
  4. 10분~1시간 후 자동 연결, SSL(https)도 자동 발급

HTML 안의 도메인 자리 교체

다음 파일에서 YOUR_DOMAIN을 본인 도메인으로 일괄 교체하세요:

  • index.html — og:url, og:image, canonical, JSON-LD 안
  • robots.txt — sitemap URL
  • sitemap.xml — 페이지 URL

7최종 체크리스트

  • 모든 파일이 GitHub에 올라감
  • Vercel에서 사이트가 정상 표시됨
  • 휴대폰으로도 열어서 모바일 디자인 확인
  • Formspree ID 교체 → 본인 메일로 테스트 제출
  • GA 측정 ID 입력 → 실시간 보고서에서 본인 접속 확인
  • 전화번호 02-1234-5678 → 실제 번호로 교체 (index.html, blog.html, 푸터)
  • 이메일 hello@erum-marketing.kr → 실제 메일로 교체
  • 사업자등록번호, 대표자명 → 실제 정보로 교체
  • 네이버 블로그 ID — blog.html의 YOUR_BLOG_ID 2곳 교체
  • 성공사례 이미지 → 실제 병원 사례 이미지로 교체 (병원 동의 후)
  • 도메인 연결 (선택)
  • 네이버 서치어드바이저, 구글 서치콘솔에 사이트 등록
