1
현재 site 폴더 다운로드 받기
PC에 현재 작업 결과물을 ZIP으로 받기

💾 다운로드 방법

  • 1
    화면 왼쪽 파일 트리에서 site 폴더를 찾기
  • 2
    site 폴더 위에서 마우스 우클릭 → 다운로드(Download) 클릭
    ZIP 파일로 저장됩니다 (예: site.zip)
  • 3
    다운받은 ZIP을 바탕화면이나 다운로드 폴더에서 압축 풀기
    Windows: 우클릭 → 압축 풀기 / Mac: 더블클릭

📁 압축 풀면 이런 구조여야 정상

site/ ├── index.html ← 메인 페이지 ├── blog.html ← 칼럼 페이지 ├── cases.html ← 성공사례 페이지 ├── deploy_guide.html ← 초기 배포 가이드 ├── update_guide.html ← 부분 업데이트 가이드 ├── upload_guide.html ← 이 가이드 ├── styles.css ← 전체 디자인 ├── sections.css ← 섹션별 디자인 ├── script.js ← 동작 스크립트 ├── tweaks.js ← 색상/무드 토글 └── assets/ ├── logo.png, og-image.png ├── case-dental.png, case-derm.png, case-ortho.png ├── partner-1.png ~ partner-6.png └── clients/ └── client-01.png ~ client-19.png (병원 로고)
⚠️ assets/clients/ 폴더 안에 병원 로고 PNG 파일들이 들어 있는지 꼭 확인하세요. 이게 없으면 협력병원 marquee가 깨집니다.
2
GitHub 기존 파일 정리하기
옛날 파일을 지워서 충돌을 막습니다

🧹 기존 파일 삭제

  • 1
    github.com → Your repositories → erum-marketing 클릭
  • 2
    저장소 메인 화면에 있는 모든 파일을 하나씩 삭제
    파일 클릭 → 우측 상단 휴지통(🗑️) 아이콘 → 아래로 스크롤 → Commit changes
  • 3
    assets 폴더도 들어가서 그 안의 파일들도 같은 방식으로 삭제
    assets/clients/ 폴더 안까지 모두 비우기
🖼️ 화면 설명
파일을 클릭하면 화면 오른쪽 위에 연필 아이콘(편집)과 휴지통 아이콘(삭제)이 보입니다.
휴지통 아이콘을 클릭 → 가장 아래로 스크롤 → "Commit changes" 버튼 클릭하면 삭제 완료.
⚠️ 저장소(Repository) 자체를 삭제하지 마세요. 저장소를 지우면 Vercel 연결이 끊겨서 다시 설정해야 합니다. 파일만 지우는 게 핵심입니다.
💡 귀찮으면 건너뛰어도 됩니다. 같은 이름의 파일을 다시 올리면 자동으로 덮어씌워지거든요. 단, 이전 버전에만 있던 파일(예: client-04.webp)은 안 지우면 그대로 남습니다. 깔끔하게 가려면 정리하는 게 좋아요.
3
새 파일 일괄 업로드하기
압축 푼 site 폴더 내용물을 GitHub로 드래그

📤 루트(저장소 메인)에 업로드

  • 1
    저장소 메인 화면에서 Add file → Upload files 클릭
  • 2
    압축 푼 site 폴더 안의 모든 파일과 폴더를 전체 선택 (Ctrl+A / Cmd+A)
    ⚠️ site 폴더 자체가 아니라, 폴더 안의 내용물을 선택
  • 3
    선택한 파일/폴더를 GitHub 업로드 화면의 점선 박스 안으로 드래그
    assets 폴더도 폴더째 끌어다 놓으면 자동으로 하위 파일까지 다 올라갑니다
  • 4
    파일이 모두 업로드된 걸 확인한 뒤, 화면 아래 "Commit changes" 클릭
    메시지 칸은 비워도 됩니다 (또는 "현재 버전 일괄 업로드" 정도)
🖼️ 화면 설명
GitHub 업로드 화면에는 큰 점선 박스가 있어요.
파일 탐색기에서 압축 푼 site/ 폴더를 열고,
그 안의 파일/폴더만 전체 선택 → 드래그해서 점선 박스에 놓으면 됩니다.
파일이 많으면 업로드에 1~2분 걸릴 수 있어요.
💡 중요: index.html이 GitHub 저장소 맨 위(루트)에 있어야 Vercel이 찾을 수 있습니다. site/index.html처럼 폴더 안에 들어가 있으면 사이트가 안 떠요.
⚠️ 만약 폴더 통째 드래그가 안 되면? → assets 폴더만 따로 업로드하세요. 저장소에서 Add file → Create new file → 파일명에 assets/clients/임시.txt처럼 입력하면 폴더가 만들어집니다. 그 다음 그 폴더에 들어가서 이미지를 업로드하면 됩니다.
4
Vercel 자동 배포 확인하기
GitHub에 올리면 1~2분 후 자동 반영

✅ 배포 상태 확인

  • 1
    vercel.com 접속 후 로그인
  • 2
    대시보드 → 이룸마케팅 프로젝트 클릭
  • 3
    Deployments 탭에서 맨 위 항목 상태 확인
    🟡 Building → ✅ Ready 로 바뀌면 완료
  • 4
    Ready 뜨면 erum-marketing.vercel.app 새로고침
✅ 배포 성공! 이제 라이브 사이트에 최신 버전이 반영됩니다.
⚠️ 예전 화면이 보이면? → Ctrl+Shift+R (Mac: Cmd+Shift+R)로 강력 새로고침. 브라우저 캐시 문제입니다.

최종 확인 체크리스트
라이브 사이트에서 하나씩 확인

    메인 페이지(/)가 정상적으로 열리는지

  • ✓
    Hero 문구가 "매출 안 오르면 100% 환불"인지
  • ✓
    Stats 숫자 3개 (3.2년 / 97% / 617%)가 보이는지
  • ✓
    함께하는 병원 marquee가 끊김 없이 3줄 흐르는지
  • ✓
    병원 로고 19개가 모두 보이는지 (에미뜨/라라피부과 검정 글씨)
  • ✓
    서비스 카드 캐러셀에 11개 카드가 다 보이는지 (메타 아이콘 포함)
  • ✓
    Process 5단계가 가로로 늘어서 있는지
  • ✓
    FAQ 5개 질문이 클릭 시 펼쳐지는지
  • ✓
    Contact 폼 — 동의 체크 안 하면 alert 뜨는지
  • ✓
    휴대폰으로 열어서 모바일 디자인 깨지지 않는지
  • ✓
    본인 메일로 문의폼 테스트 제출 → 메일 도착 확인
