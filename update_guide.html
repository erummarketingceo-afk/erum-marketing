2
GitHub에 파일 올리기
github.com에서 드래그앤드롭으로 업로드

🖥️ GitHub 저장소 열기

  • 1
    github.com 접속 후 로그인
  • 2
    우측 상단 프로필 사진 클릭 → Your repositories 클릭
  • 3
    펜타마케팅 저장소 클릭 (예: penta-marketing)

📤 파일 업로드하기

  • 1
    저장소 화면에서 Add file 버튼 클릭 → Upload files 선택
  • 2
    업로드 화면이 나오면, site 폴더 안의 파일들을 전부 드래그해서 점선 박스 안에 놓기
    ※ site 폴더 자체가 아니라, 폴더 안의 내용물을 선택해서 드래그
  • 3
    assets 폴더도 같이 드래그 (폴더째로 드래그 가능)
  • 4
    파일이 다 올라오면 아래 "Commit changes" 버튼 클릭
    메시지 칸은 비워도 됩니다
🖼️ 화면 설명
GitHub 업로드 화면에는 큰 점선 박스가 있어요.
거기에 파일/폴더를 드래그해서 놓으면 자동으로 업로드됩니다.
업로드가 끝나면 맨 아래 초록색 "Commit changes" 버튼을 누르면 완료!
💡 같은 이름의 파일을 올리면 자동으로 덮어씌워집니다. 기존 파일 걱정 없이 그냥 올리면 돼요.

📂 assets/clients/ 폴더는 이렇게 올리기

  • 1
    GitHub 저장소에서 assets 폴더를 클릭해서 들어가기
  • 2
    Add file → Upload files 클릭
  • 3
    assets/clients/ 폴더 안의 병원 로고 이미지 17개를 드래그해서 올리기
  • 4
    Commit changes 클릭
💡 GitHub는 폴더 구조가 그대로 유지됩니다. assets 폴더 안에 들어가서 업로드하면 assets/clients/파일명으로 저장돼요.
3
Vercel 자동 배포 확인하기
GitHub에 올리면 1~2분 후 자동으로 사이트에 반영됩니다

✅ 자동 배포 확인 방법

  • 1
    vercel.com 접속 후 로그인
  • 2
    대시보드에서 펜타마케팅 프로젝트 클릭
  • 3
    상단에 "Building..." 또는 "✅ Ready" 상태 확인
    Building 중이면 1~2분 기다리면 됩니다
  • 4
    Ready 뜨면 penta-marketing.vercel.app 새로고침해서 확인
🖼️ Vercel 화면 설명
Vercel 대시보드에서 프로젝트를 클릭하면
오른쪽에 Deployments(배포 목록)이 나옵니다.
맨 위 항목 옆에 🟡 Building → ✅ Ready로 바뀌면 완료!
보통 1~2분 걸립니다.
✅ 배포 성공! 이제 penta-marketing.vercel.app을 열면 수정된 홈페이지가 보입니다.
⚠️ 사이트를 열었는데 아직 예전 화면이 보인다면? → 브라우저에서 Ctrl+Shift+R (Mac: Cmd+Shift+R)로 강력 새로고침 해보세요. 캐시 문제일 수 있어요.
